2026-04-14  Initial Release (v1.0)
──────────────────────────────────────────────────────────────────────────────

[NEW] math_engine.py
  - Safe expression parser with restricted namespace (sin, cos, tan, arcsin,
    arccos, arctan, sinh, cosh, tanh, sqrt, ln, log, exp, abs, pi, e)
  - Domain-aware evaluation: division by zero → NaN, complex results → NaN,
    negative logarithm arguments → NaN
  - Numerical gradient via central finite differences
  - Numerical Hessian matrix computation
  - Directional derivative D_u f
  - Critical-point detection via scipy.optimize with second-derivative-test
    classification (local min / local max / saddle / inconclusive)

[NEW] tabs/__init__.py
  - Empty init for the tabs package

[NEW] tabs/surface_tab.py
  - Tab 1: f(x,y) Visualizer
  - Surface plot (3D), filled contour (level curves), contour lines, combined
    (2×2 grid) plot modes
  - Multiple simultaneous functions via Add/Remove/Update listbox
  - Adjustable x/y ranges and grid resolution
  - Cross-section slicing along x or y axis with interactive sliders
  - Colormap selector (viridis, plasma, inferno, coolwarm, RdYlBu, Spectral)
  - Hover readout showing f(x,y) at cursor position

[NEW] tabs/level_surface_tab.py
  - Tab 2: f(x,y,z) Level Surfaces
  - Isosurface rendering f(x,y,z) = c using scikit-image marching cubes
  - Adjustable level value (c), x/y/z domain ranges, and resolution
  - Axis-aligned cross-section slicing (x, y, or z) with slider
  - 2D filled contour of the slice with level-contour overlay
  - Colormap selector

[NEW] tabs/analysis_tab.py
  - Tab 3: Calculus Analysis
  - Gradient vector field overlay (quiver plot, normalized arrows)
  - Gradient at a specified point (x₀, y₀) with highlighted arrow and label
  - Directional derivative in a user-specified direction (dx, dy) or angle θ°
  - Critical-point detection and classification with marker overlays:
      ● green circle  = local minimum
      ▲ red triangle  = local maximum
      ◆ yellow diamond = saddle point
  - Info panel showing ∇f, |∇f|, D_u f, and critical point list
  - Contour background with colormap selector

[NEW] main.py
  - Tkinter entry point with ttk.Notebook (3 tabs)
  - Window: "Real-Valued Functions Applet", 1400×900
  - Uses 'clam' theme with Segoe UI bold tab labels

[NEW] build.py
  - PyInstaller build script producing a single-file windowed executable
  - Hidden imports: numpy, matplotlib, scipy, skimage

NOTES:
  - PyTorch was planned for differentiation but is incompatible with
    Python 3.14; all differentiation uses NumPy central finite differences.
  - scikit-image ≥ 0.26 is required for marching cubes (already installed).
